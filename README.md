# uchimado（うちまど）

**暮らしを映す、もうひとつの窓。**

uchimado（うちまど）は、予定・タスク・メモなど、日々の暮らしに必要な情報を一か所で見渡し、管理・共有する家庭向けダッシュボードです。一人暮らしから複数人での利用まで、壁掛けタッチディスプレイ・スマートフォン・PCでの利用を目指しています。

製品方針はユーザー管理の [PROJECT_SPEC](docs/PROJECT_SPEC.md)、今回の対象は [PHASE_1](docs/PHASE_1.md)。既存HomeBoardのKagiroiデザイン、ホーム、ドック、カレンダー、ウィジェット配置を引き継いでいます。

## Kagiroi Design System

Kagiroi（かぎろひ）は、光の透過・柔らかな陰影・奥行きを取り入れたuchimadoのデザインシステムです。Fluent DesignとGlassmorphismを参考に、写真背景と半透明カード、フローティングドック、編集パネルを組み合わせています。

読みやすさとタッチ操作を優先し、配色・角丸・影・動きは `src/styles.css` のトークンで管理します。背景ぼかし、透明度、動きの軽減、軽量モードも設定できます。

## Windowsで起動

Python 3.11以上（検証: 3.13）、Node.js 22.12以上が必要です。

```powershell
git clone https://github.com/hirokawa-beach/uchimado.git
cd uchimado
.\setup-uchimado.ps1
.\start-uchimado.ps1
```

[http://localhost:8000](http://localhost:8000) を開くと、ログインなしで家族共通のホームを使えます。管理者の初期設定は「メニュー → 設定 → 管理者パターンを設定」から、サーバーPCのlocalhostで行います。家族プロフィールにパスワードは不要です。予定・タスク・メモは空で始まり、DBはAlembicマイグレーションで維持します。

導入済みのこのチェックアウトでは `start-uchimado.cmd` のダブルクリックでも起動できます。終了は起動したターミナルでCtrl+C。

家庭内LANから使う場合は、管理者パターンと回復コードを設定・保管してからLAN用に再起動します。既存版からの更新時も、旧サーバーを停止して再起動してください。旧DBは更新前に `data/backups/before-auth-v2-*.sqlite3` へ自動退避します。旧ユーザーはプロフィールに移行し、旧パスワードとセッションは失効します。

```powershell
.\start-uchimado.ps1 -Lan
```

他の機器では `http://サーバーPCのLAN内IP:8000` を開きます。Windowsファイアウォールでは必要なプライベートネットワークだけ許可してください。外部公開やルーターのポート開放は行いません。

## Linux / Raspberry Pi向けの起動手順

```sh
git clone https://github.com/hirokawa-beach/uchimado.git
cd uchimado
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
npm ci
npm run build
.venv/bin/python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000 --no-access-log
```

Piのブラウザーから管理者パターンを初期設定し、Chromiumのキオスク表示を利用できます。Pi実機・タッチモニター・OSのソフトウェアキーボード・常時稼働性能は未検証です。systemdやHTTPSの本番構成はPhase 4で拡充します。

## 使い方

- ホームのカード、下のドック、メニューから各アプリへ移動します。
- カレンダーは月・週・日表示。月の日付を選ぶと日表示へ移り、予定を開いて編集できます。
- 予定は終日・色・担当・場所・説明・繰り返しを設定できます。現在の公開範囲は家族共通です。日付と時刻は日本時間です。
- 繰り返し予定は「この回だけ」または「シリーズ全体」を選択。全体の更新は過去の回にも適用し、個別変更・取消をリセットします。毎月31日など、同じ日付のない月はスキップします。
- タスクは担当・期限・優先度・繰り返しを設定できます。繰り返しタスクを完了すると履歴へ記録し、現在の期限から1回分先へ進みます。期限超過分を自動消化しません。
- 掲示板で複数のメモを作成・編集・削除・ピン留めできます。ホームは最新更新のメモを表示します。
- 予定・タスク・メモには内蔵かな／英数キーボードがあります。漢字変換はOSの日本語入力を利用してください。
- 「メニュー → ウィジェットを配置」で追加・削除・移動・サイズ変更・保存。管理者解除なしで、端末種別（壁掛け／スマホ）ごとの家族共通設定としてDBへ保存します。
- 「メニュー → 設定」で誰でも外観を編集し、**「外観を保存」**でサーバーへ保存します。背景写真もこの時点で家族のサーバーへ送信されます。
- 設定の「作成者として使う名前」で、メモや予定の作成者として記録する名前を選びます。予定・タスクの担当者は編集画面で別に指定します。通常利用にログイン画面はなく、選択は認証を意味しません。プロフィールごとのパスワード・パターンもありません。
- 「管理者を解除」で3×3のパターンを入力すると、15分間だけプロフィール管理・システム設定・バックアップを利用できます。管理者は家族プロフィールとは別に1つだけです。「管理者をロック」で早めに終了できます。
- 旧非公開データはDBに保持し、プロフィール選択や管理者解除だけでは表示しません。新規の非公開データ作成も現在は提供しません。
- 通信中・再接続中・失敗は画面に表示します。失敗した入力は編集フォームに残します。同時編集は409で拒否し、古い入力を勝手に上書きしません。

## 保存・権限・同期

FastAPI / SQLAlchemy / SQLite / Alembic、RESTとWebSocketのモジュラーモノリスです。DBの既定位置は `data/uchimado.sqlite3`。`UCHIMADO_DB`環境変数で変更できます。`.env.example`は変数例で、自動読み込みはしません。

家族プロフィールは名前・ID・使用状態のみを扱います。選択IDは端末のlocalStorageへ保存しますが、本人確認や権限には使いません。旧ユーザーのIDを引き継ぐため、過去の作成者も区別できます。

管理者パターンはソルト付きscrypt（N=2^17, r=8, p=1）で保存します。管理者セッションは発行から15分間の固定期限で、HttpOnly/SameSite=Strict CookieとDB側のトークンハッシュで管理します。APIでも期限・認証世代を確認します。パターン認証は全体／接続元ごとに15分間で5回失敗すると制限し、再起動しても制限を維持します。

既存の非公開予定・メモ・個人設定等は保全しますが、通常API・履歴APIからは返しません。管理者のDBバックアップにはそれらも含まれます。外観・配置は、誰でも変更できる端末種別ごとの家族共通設定です。プロフィール管理・家族名・バックアップ・復元・パターン変更は管理者専用です。

更新・削除・設定保存にはバージョンを使用します。DBトランザクションのコミット後に、内容を含まない変更通知を送信します。各端末は権限に応じて状態を再取得します。再接続・画面復帰・30秒ごとの照合も実施します。WebSocketの通知配信は単一プロセス方式なので、**Uvicornは1ワーカーで運用**してください。

旧プロトタイプのソース・localStorageは変更しません。新アプリは旧ブラウザーデータを自動送信せず、空のDBから始めます。必要な実データが旧公開版にある場合は、そのブラウザーのデータを保護し、移行を別途実施してください。

## バックアップ・復元

管理者パターンで解除した後、設定画面の「DBバックアップ」で、稼働中でも整合したSQLiteコピーをダウンロードできます。サーバーにも `data/backups/` にコピーが残ります。個人データを含むため、保管場所のアクセス権限と世代管理は管理者が行ってください。

CLIバックアップ（現在の管理者パターンを対話入力します。点は左上から1〜9の番号）:

```powershell
.\.venv\Scripts\python -m backend.manage backup backups\uchimado-2026-11-08.sqlite3
```

復元はすべてのサーバープロセスを停止してから実行します。現在の管理者パターンを対話入力する必要があります。

```powershell
.\.venv\Scripts\python -m backend.manage restore backups\uchimado-2026-11-08.sqlite3 --server-stopped
.\start-uchimado.ps1
```

復元前DBは `before-restore-*.sqlite3` として退避します。復元では整合性と必須テーブルを確認し、全セッションを失効させます。現在の管理者パターンと回復コードを引き継ぐため、バックアップ中の古い認証情報を復活させません。保存した秘密情報がコピーへ残ることもあるため、バックアップは端末や家庭内の適切な保存先で管理してください。通常の起動や更新でDBを初期化する処理はありません。

## パターンを忘れた場合

初回設定やパターン変更時に表示される回復コードを、端末とは別の安全な場所へ保管してください。画面の保存ボタンからテキストファイルにもできます。DBには回復コードのダイジェストのみを保存し、コードは再表示しません。

「管理者を解除 → パターンを忘れた」から、回復コードと新しいパターンを入力します。コードは一回限りで、成功すると新コードに入れ替わります。全管理者セッションが失効し、自動解除はしません。新コードを保管した後、新パターンで解除してください。回復コードの入力も、全体／接続元ごとに15分間で3回失敗すると制限します。

回復コードも失った場合は、サーバーを停止し、サーバーOS上のDB保守権限を持つ管理者が実行します。

```powershell
.\.venv\Scripts\python -m backend.manage issue-admin-recovery --server-stopped
```

このコマンドは新しい一回限りの回復コードをローカルコンソールへ表示します。旧回復コードと全管理者セッションを失効させます。再起動後、上記の復旧画面から新パターンを設定してください。LANから誰でもパターンを消すAPIや既定の解除パターンは用意していません。

## 開発・検証

開発用APIとViteは別ターミナルで起動します（初期DBも通常の `data/` を使用）。

```powershell
.\.venv\Scripts\python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
npm run dev
```

Viteは `/api`（WebSocketを含む）をAPIへ転送します。

```powershell
npm run typecheck
npm test
npm run build
.\.venv\Scripts\python -m pytest tests/test_api.py -q
```

自動テストのDB、ブラウザーQA用DB、スクリーンショットは無視対象の `artifacts/` へ保存します。現在の認証仕様と検証は [AUTH_ACCOUNT_SPEC](docs/AUTH_ACCOUNT_SPEC.md)。初回実装計画は [IMPLEMENTATION_PLAN](docs/IMPLEMENTATION_PLAN.md)、検証の記録と残課題は [IMPLEMENTATION_STATUS](docs/IMPLEMENTATION_STATUS.md) を参照してください。

GitHub ActionsはPush・Pull Request時にTypeScriptの型チェック、フロントエンドテスト、ビルド、Ubuntu／Windowsでのバックエンドテストを実行します。実データや認証情報は不要です。

## Gitでの開発

`main` を安定版、`feature/*` を新機能、`fix/*` を不具合修正に使い、Pull Requestで変更を確認します。コマンド例と検証手順は [CONTRIBUTING.md](CONTRIBUTING.md) を参照してください。

DBの実データ、アップロード画像、認証情報、秘密鍵、ログ、仮想環境、ビルド結果は `.gitignore` で除外しています。DBスキーマとマイグレーション、秘密情報を含まない `.env.example` はGit管理します。
