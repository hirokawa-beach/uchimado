# 操作性の改善予定

初回リポジトリ登録時点のPhase 1には、次のUI改善が残っています。機能追加とは分けて修正ブランチで進めます。

- ネイティブのプルダウンを、タッチしやすい選択方式へ変更する。
- スクリーンキーボードを入力欄の近くに表示し、画面の下端で操作不能にならないようにする。
- 一人での利用にも合う表記に整え、共通の作成者選択とアプリ一覧の名前・同期済み表示をなくす。
- 編集の破棄確認をダイアログに統一する。
- 背景ぼかし0で残るぼかしを修正し、分かりやすい調整とプレビューを用意する。
- カレンダー週表示の中央揃えと、パレットでの色選択を整える。
- タスク一覧に完了チェックと明示的な編集ボタン、掲示板に編集ボタンを設ける。
- ホームのメモ書き換えボタンを省く。
- ホーム配置設定の重複した囲みを減らし、設定画面の配置を整える。

通常のホーム設定は管理者解除なしで使える状態を維持します。プロフィール管理・家族名・バックアップ／復元・管理者パターン変更の権限保護も維持します。
