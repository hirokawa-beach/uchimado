# 操作性の改善（2026-11-08）

ユーザーから指摘された次の改善を実装しました。

- プルダウンをタッチ用の選択ボタンへ変更。時・分、繰り返し間隔、多数のプロフィールはスクロールできる選択ダイアログを使います。日付は端末の日付ピッカーを使います。
- テキスト欄のフォーカス・タップでキーボードを近くに表示。空きに応じて上下を切り替え、画面内に収めます。入力欄の切り替え・スクロール・画面サイズ変更にも追従し、閉じる／端末キーボードへの切り替えができます。回復コードは既存のパスワード欄を維持します。
- アプリ名や案内を一人での利用にも合う表記へ変更。既存データの担当「家族」は画面上で「共通」と表示し、保存データやプロフィール名は書き換えません。
- 全体の作成者選択と、アプリ一覧の名前・同期表示を削除。予定・タスク・メモの新規作成時に作成者を任意で選択し、APIで有効なプロフィールか確認します。既存の作成者履歴は保持します。
- 予定・タスク・メモ・ホーム配置・外観の破棄確認をモーダルダイアログへ統一。削除確認もダイアログにしました。
- 背景・ドックに別々に残るぼかしを解消。調整値を「なし・弱め・中くらい・強め」で示し、背景全体への一時プレビューと写真プレビューを追加。保存前に移動を取り消せば元の外観に戻せます。軽量モード時はぼかしを無効にします。
- 週表示の日付の中心を列中央に揃え、予定の色をパレット選択に変更。既存の独自色も選択肢に保持します。
- タスク一覧から完了・未完了を直接切り替え、各項目に編集ボタンを追加。繰り返しと完了履歴の処理は維持します。
- 掲示板に明示的な編集ボタンを追加し、ホームのメモ書き換えリンクを削除。
- ホーム配置設定を一つの行全体のボタンに整理。設定は見出し・保存操作、ホーム配置、外観、管理者設定の順に配置し、管理者の操作範囲を明記。

通常のホーム設定は管理者解除なしで使えます。プロフィール管理・ボード名・バックアップ／復元・管理者パターン変更のAPI保護と、旧非公開データの非開示を維持します。
