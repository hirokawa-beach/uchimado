# Kagiroi + CSS Modules

2026-11-09。既存の画面表示・動作を維持し、スタイルの所有範囲を分離しました。React / TypeScript / Vite / Radix UI / Lucide、API、DB構造は変更していません。

## ファイルの責任

| ファイル | 責任 |
| --- | --- |
| `src/styles/reset.css` | フォーム、文字、画像、日付入力などのブラウザー標準の差を初期化。低い優先度のresetレイヤーに置く |
| `src/styles/tokens.css` | 既存名を維持した色・余白・角丸・モーション等の変数。アニメーション名も変数経由で共有 |
| `src/styles/themes.css` | ダークテーマの変数、ホームのテーマ別Surface設定 |
| `src/styles/global.css` | 基本文字、Surface、ボタン、フォーム、共通の状態、アクセシビリティ、共通アニメーション |
| `src/*.module.css` | 画面・コンポーネントのローカルなスタイル |

17本のCSS Modules：Shell、Home、ForecastWidget、Navigation、SettingsPage、PrototypePage、EventEditor、CalendarPage、WidgetEditor、TasksPage、BoardPage、AccountPanel、AdminAccess、PatternLock、CoreProvider、TouchControls、TouchText。

共通の `button`、`surface`、`field-label`、`form-actions`、色・テーマ・表示状態のクラスは必要な範囲でグローバルに残しています。Moduleからこれらを参照する場合だけ `:global(...)` を使用します。画面固有のルールをglobal.cssへ追加しないでください。

## コンポーネントでの使い方

既存のケバブケースのクラス名を維持しています。単独のクラスなら `styles['class-name']` で参照でき、既存の複数クラスや動的な組み立てには `cssNames(styles, value)` を使います。共通クラスはそのまま、ローカルクラスはCSS Modulesの出力名へ解決します。

```tsx
import styles from './TasksPage.module.css'
import {cssNames} from './cssNames'

<article className={cssNames(styles, `surface task-resource ${done ? 'completed' : ''}`)} />
```

Portalの挿入先は `[data-app-shell]`、破棄確認のフォーカス先は `[data-confirm-dialog] [data-confirm-cancel]`、キーボードの操作判定は既存の `[data-touch-keyboard]` です。生成されたクラス名をquerySelectorから参照しないでください。

## 撤去した依存

- `tailwindcss` と `@tailwindcss/vite`、関連する間接依存。
- ViteプラグインとCSSのフレームワーク読み込み。
- `sr-only` と `flex-1` の使用。独立した非表示用クラス・編集フォームのスペーサーへ置換。
- 旧7本のグローバルCSS。共通部分を4本の基盤CSS、固有部分を17本のModulesへ移動。

依存パッケージ・ロックファイル・ビルド設定・実行ソースにフレームワーク依存は残していません。所有者管理の `docs/PROJECT_SPEC.md` にある旧技術スタックの記述は変更していません。実装の現在値はこの文書とREADMEを参照してください。
